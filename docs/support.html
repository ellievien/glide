Glide Support

Glide, by Neverheard Studio

Glide sends files directly between your devices over your local network — no cloud, no account, no size limits. This page covers common questions and how to reach us.

Two devices can't find each other

  • Make sure both devices are connected to the same Wi-Fi network. Glide discovers devices on the local network only; it cannot find devices on cellular data, a different Wi-Fi network, or across a guest/isolated network.
  • Some routers isolate devices from each other for security ("client isolation" or "AP isolation"). If discovery doesn't work on a given network, check the router's settings for this option.
  • Make sure Glide has been granted local network permission: on iOS, check Settings > Glide > Local Network is turned on.
  • Try closing and reopening Glide on both devices to restart discovery.

A transfer failed or was slow

  • Transfers happen directly between devices, so speed depends on your Wi-Fi network, not on an internet connection. A weak Wi-Fi signal on either device will slow a transfer down.
  • Keep both devices on-screen (not locked) and within Wi-Fi range for the duration of the transfer.

Saving received files

Received photos and videos can be saved to your device's photo library from the transfer screen. Other file types are kept in Glide's own file storage, which you can browse from the app.
