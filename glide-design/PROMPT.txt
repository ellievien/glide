Implement Glide's complete app UI from the design package in the `glide-design/` folder of this repo.

Start by reading `glide-design/GLIDE_DESIGN_SPEC.md` in full — it defines the design tokens, the reusable components, all six screens plus the extra states, the navigation map, the exact copy, the motion spec, the icon set and the brand assets. The files in `glide-design/reference/` are the pixel-exact source of truth for every screen; `glide-design/icons/` is the icon set to use; `glide-design/brand/` has the logo, symbol and every platform's app icon.

Build everything the spec describes — every screen, state, component, icon and animation, and wire up the app icons for each platform this project targets — using this codebase's existing framework, navigation, theming and state patterns. Bind everything to real app data (no placeholder device or file names left in). Follow section 9 of the spec for the rules: tokens in one place, real accessible controls, reduced-motion handling, no additions outside the spec, verify each screen against the reference HTML, and don't stop to ask questions — decide, then list your decisions and anything you couldn't finish at the end.
